## 🎯 Product Charter & End Scope Vision

NanoHat is an **all-time active, autonomous AI agent and OS caretaker** for Fedora Workstation. It runs continuously in the background to diagnose, analyze, set reminders, manage services, and take care of the operating system—making the user's computing life effortless while strictly adhering to the Linux ethos:

1. **Absolute Privacy & Sovereignty**: 100% local execution (Ollama/GGUF). Zero telemetry, zero cloud dependencies, zero external network leakage.
2. **Extreme Resource Efficiency**: Designed to run comfortably on a single CPU core and entry hardware (4GB–8GB RAM systems). The model footprint is capped under ~300MB RAM (`FunctionGemma 270M` or sub-1B Q4_K_M).
3. **No Flashy Bloat**: We reject gimmicks (e.g. typing to take a screenshot or lock the screen). We deliver reliable, deterministic, daily-driver functionalities.
4. **Safety by Default**: Destructive operations fail closed. Zero shell string interpolation (`shell=False`). No dangerous process termination.

| Pillar | Capabilities | Implementation Mechanism | Safety / Gate |

| **1. System Telemetry & Caretaker** | CPU, RAM, disk, battery metrics, thermal stats, service diagnostics | `psutil`, `systemctl --user status` | Read-only |

#### 🚫 Explicitly OUT OF SCOPE (The Anti-Scope)
- ❌ Open-web scraping or internet search in the core daemon (fragile, noisy, violates offline privacy).
- ❌ Process slaughtering (`kill_process`) — unacceptable risk of killing `systemd`, `gnome-shell`, or the agent itself.
- ❌ Bloated multi-gigabyte models that throttle entry laptops.
- ❌ Heavy Electron/web GUIs. NanoHat is a native CLI binary and background systemd service.

## 🛡️ Non-Negotiable Engineering Requirements

1. **100% Offline & Deterministic**: Zero network calls required for any core v3.0.0 functionality.
2. **Sub-300M Model Alignment**:
   - Model: `functiongemma:latest` (268M parameters, Q8_0, 300MB RAM footprint).
   - In-context balanced few-shot exemplars preventing refusal loops.
   - Clean JSON tool schemas compliant with OpenAI/Ollama tool specification.
3. **Zero Shell Interpolation**: All command invocations must use argument lists (`subprocess.run(["cmd", "arg"], shell=False)`).
4. **Fail-Closed Security Gates**: Destructive operations (`kill_process`, `restart_service`, `empty_trash`, `memory_delete`) must prompt the user interactively or require `NANOHAT_AUTO_APPROVE_DESTRUCTIVE=1` in headless mode.
5. **Machine-Checkable Contracts**: All tool functions return structured strings (`OK: ...` or `ERROR[reason]: ...`).
