# 🧪 NanoHat v3.0.0 Manual Test Matrix & QA Checklist

- **Target System**: NanoHat v3.0.0 (`functiongemma:latest`, 268M Q8_0)
- **Scope**: 16 Frozen Tools across 5 Core Pillars (ADR-007 Lean Scope)
- **Harness**: Sub-1B Dynamic Tool Gating ($\le 3$ active tools per query)
- **Execution**: Run directly via `nanohat "<query>"` or `nanohat --verbose "<query>"` in terminal.

---

## 💡 Quick Tips for Manual Testing
- Add `--verbose` to inspect the routed tool and model invocation steps:
  ```bash
  nanohat --verbose "What is my battery level?"
  ```
- To inspect or reset the SQLite state database:
  ```bash
  sqlite3 ~/.local/state/nanohat/state.db "SELECT * FROM user_memory;"
  sqlite3 ~/.local/state/nanohat/state.db "SELECT * FROM scheduled_tasks;"
  ```
